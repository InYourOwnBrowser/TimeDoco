Privacy Policy

1. 100% Client-Side Storage

TimeDoco is designed as a privacy-first, 100% client-side application. All time entries, client names, billable rates, project groups, and settings are stored locally in your browser using IndexedDB. No operational data is ever transmitted to or stored on external application servers.

2. Zero Tracking, Telemetry, or Analytics

TimeDoco does not contain third-party tracking scripts, advertising tags, telemetry monitors, or analytics services. We do not track your usage habits, click paths, feature interactions, or performance metrics.

3. No Cookies or Cloud Accounts

TimeDoco does not require user registration, passwords, or cloud authentication. The application does not use tracking cookies or persistent identifiers to profile users across sessions or sites.

4. Hosting Infrastructure & Server Access Logs

This website is served as static web content. When you access this site, the underlying web hosting infrastructure (such as GitHub Pages or CDN providers) automatically logs standard web access requests (including IP address, browser user-agent, and request timestamp) for security, rate-limiting, and network delivery purposes. These infrastructure logs operate independently of the TimeDoco application code.

5. Data Ownership & Export

Because your data remains exclusively on your device, you have full ownership and control over it. You can generate full JSON backups, export CSV logs, print client-facing PDFs, or clear your local IndexedDB storage at any time directly through your browser or the application Settings modal.
